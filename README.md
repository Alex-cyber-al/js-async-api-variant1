Практична робота 10.2
Варіант 1: GitHub User Explorer

Опис проєкту

Додаток дозволяє:

- шукати користувачів GitHub;
- переглядати профіль;
- переглядати репозиторії;
- сортувати репозиторії за кількістю зірок;
- працювати з GitHub API.

Використані технології

- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await
- Promise.all

API

GitHub API:
https://api.github.com/

Запуск проєкту

1. Відкрити папку проєкту у VS Code
2. Запустити index.html через Live Server

Функціонал

- Пошук користувача GitHub
- Відображення профілю
- Список репозиторіїв
- Error handling
- Loading state
- Responsive дизайн
